## 容易混淆的几组

- **停止和成功**：停止是执行状态；成功需要满足验收。
- **模型说做了和工具实际做了**：前者是陈述；后者需要执行记录与外部证据。
- **消息到达和任务完成**：投递只完成通信中的一环。
- **测试通过和获准发布**：质量结论与操作授权不同。
- **上下文隔离和权限隔离**：分别控制看见什么信息与能执行什么动作。
- **持久化和恰好一次**：保存状态不能自动消除跨系统的重复副作用窗口。
- **不同 Agent 和不同模型**：多个 Agent 可以使用同一个底层模型；角色数量不证明能力多样性。
